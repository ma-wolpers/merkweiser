# Merkweiser

Merkweiser zeigt dir, was du dir merken musst, und hilft dir, dir Dinge weiser zu merken: Es ist eine Oberfläche für Markdown-Tagesnotizen (`YYYY-MM-DD.md`) und die Todos darin, auf dem Desktop (bw-gui) und auf Android (Flet).

- **Die Markdown-Dateien sind die einzige Wahrheit.** Obsidian und Syncthing bleiben gleichberechtigt; es gibt keine Datenbank und keine versteckten IDs.
- **Nichts geht stillschweigend verloren.** Konflikte werden sichtbar, statt geraten zu werden.

**Stand:** Gerüst. Die Go/No-Go-Spikes laufen, die Umsetzung folgt [docs/PLAN.md](docs/PLAN.md).
